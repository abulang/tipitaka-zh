# 巴利三藏·中文译本

上座部佛教巴利三藏（Tipiṭaka）的中文译本与典藏排版。

底本为第六次结集本（CSCD）。本仓库存放**成品**：可直接阅读的排版书，
以及经藏的结构化译文。

## 内容

| 目录 | 内容 |
|---|---|
| `出版物/pdf/` | 40 卷典藏排版 PDF（宋体正文，适合印刷与长期保存） |
| `出版物/epub/` | 40 卷 EPUB（适合电子阅读器） |
| `译文/sutta/` | 经藏译文，结构化 JSON，逐段巴汉对照 |

译文 JSON 每段含 `pali`（巴利原文）、`zh`（中译）、`idx`（段标识），
可直接用于二次开发、比对、检索。

## 在线阅读

- https://abhidhamma.cn/ — 镜像（海外）

## 关于这份译本

- 五十万段规模的译文，**初稿不等于定稿**。已逐部校对但仍在持续订正中。
- 译经依据巴利原文、义注、复注与 nissaya 逐词对照，专名与固定套语有统一表。
- 发现错误欢迎提 issue 或直接指出。
